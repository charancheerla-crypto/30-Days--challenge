
## Algorithm

1. Start.
2. Read `N` (number of readings, from 5 to 12).
3. Read `N` readings between 0 and 1000.
4. Calculate the sum, average, minimum, and maximum.
5. Find the second-largest distinct value.
6. Count the local peaks in the array.
7. Find the longest increasing run.
8. Read `K` and rotate the array to the right by `K` positions.
9. Display the rotated array.
10. Read the last two registration digits `R` (0 to 99).
11. Calculate `D = (R % 9) + 1`.
12. Count the readings divisible by `D`.
13. Display `D` and the divisible count.
14. Stop.
