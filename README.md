# 30-Days--challenge
1. Start
2. Read inputs: Get the total distance (km), vehicle mileage (milage), and fuelprice from the user.
3. Calculate fuel needed: Divide the distance by the mileage (fuel required = km / milage).
4. Calculate total cost: Multiply the fuel required by the fuel price (total cost = fuel required * fuelprice).
5. Display results: Print the calculated fuel required and the total trip cost.
6. Stop
